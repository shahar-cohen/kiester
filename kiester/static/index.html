KKiestera kie.ai API interface

Connect Kiester to your kie.ai account

Kiester doesn't generate anything by itself. It sends your prompts to kie.ai, a pay-as-you-go AI service, and shows you the results. To do that for you, it needs your kie.ai API key.

What is an API key?

A long secret code that lets an app use your kie.ai account — like a password, but only for apps. Anyone who has it can spend your kie.ai credits, so don't share it, post it or send it to anyone. If it ever leaks, you can reset it on the kie.ai API key page; the old one then stops working.

  1. Sign in to kie.ai, or create an account: kie.ai/login
  2. Add credits. Every generation costs credits (a few cents to a few dollars each). Prices: kie.ai/pricing · top up: kie.ai/billing. Kiester shows the estimated cost before every run.
  3. Copy your key from kie.ai/api-key (create one there if the page has none yet). Copy the whole key — it is one long line of letters and numbers.
  4. Paste it below (Ctrl+V, or ⌘+V on a Mac) and press Save and connect. Kiester checks it with kie.ai before saving.

🔒 The key is saved only on this computer (~/.config/kie/token, readable by your user only) and is sent only to kie.ai. Change it any time with the 🔑 button.
